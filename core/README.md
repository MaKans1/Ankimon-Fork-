# Core

Ankimon 2.03 plus the Ankimon 2.0 general patches: bug fixes and quality-of-life changes such as real Pokémon names, the reworked item bag, the Mart, the Pokémon PC, item and move descriptions, and goal-based pacing in Settings. See [CHANGELOG.md](CHANGELOG.md).

`files/` is the add-on itself, without the gym/, wild/ and showdown packages. `build.py` copies it into `dist/Ankimon` and then adds the packages you chose.

Always installed. Runs on its own as classic Ankimon with the patches above.
